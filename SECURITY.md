# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| Latest release | ✅ Yes |
| Current development branch | ✅ Yes |
| Older releases | ⚠️ Best effort |

## Reporting a Vulnerability

If you discover a security issue, please **do not open a public issue**.

Instead, use GitHub's private reporting flow:

- Open a private report at: https://github.com/James-HoneyBadger/HB_Scrub/security/advisories/new
- Include the affected version, platform, impact, and clear reproduction steps
- If relevant, attach a **sanitized** sample file that demonstrates the problem

## Response Expectations

The project aims to:

- acknowledge valid reports within a few business days
- investigate and reproduce the issue
- prepare a fix or mitigation as quickly as practical
- coordinate responsible disclosure before public release

## Scope

Reports are especially welcome for issues involving:

- malformed file parsing
- metadata handling or unexpected data retention
- CLI or desktop app privilege or path-handling issues
- dependency or supply-chain concerns

Thank you for helping keep HB Scrub safe and trustworthy.
